Урок 8: Функції у Python

Що таке функції у Python?

Функції — це блоки коду, які виконують певне завдання і можуть бути повторно використані.
Вони допомагають структурувати код, роблять його більш читабельним і дозволяють уникнути дублювання.

Як створити функцію?

Для створення функції в Python використовується ключове слово def, після якого йде ім'я функції та круглі дужки. Код, який виконує функція, відступає всередину.

Приклад створення функції:

def hello():
print("Hello, World!")

У цьому прикладі ми створили функцію hello, яка при виклику виводить повідомлення "Hello, World!"

Як викликати функцію?

Щоб викликати функцію, потрібно написати її ім'я та круглі дужки:

hello() # Виклик функції

Приклад:

def hello():
print("Hello, World!")
hello()

Вивід:

Hello, World!

Використання функції в Математичних Обчисленнях

Функції дуже корисні для виконання повторюваних завдань, таких як математичні обчислення. Наприклад, ми можемо створити функцію для обчислення площі кола:

def add(a, b):
return a + b

result = add(5, 3)
print(f"Сума чисел 5 і 3: {result}")

Вивід:

Сума чисел 5 і 3: 8

Тут створюється функція з назвою add.
def — команда для створення функції.
add — назва функції.
a і b — параметри, які будуть отримувати значення під час виклику функції.
Команда return повертає результат обчислення.
У цьому випадку функція додає a і b, а потім повертає їхню суму.
Після створення функції ми викликаємо її з аргументами 5 і 3, і результат зберігається в змінній result. Потім ми виводимо результат на екран.
Так можна робити з будь-якими математичними операціями, створюючи функції для додавання, віднімання, множення, ділення та інших обчислень.

def multiply(a, b):
return a * b

result = multiply(5, 3)
print(f"Добуток чисел 5 і 3: {result}")

Вивід:

Добуток чисел 5 і 3: 15
Запам'ятай: Функція виконується тільки після її виклику.
